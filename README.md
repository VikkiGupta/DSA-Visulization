# 📊 DSA Visualization Application

An interactive web application built with *React* to visualize Data Structures and Algorithms (DSA). This tool helps students and developers understand how different algorithms work step-by-step through clean graphical animations.

🌐 *Live Demo:* [dsa-visulization-ei7r.vercel.app](https://dsa-visulization.vercel.app/)
---

## 🚀 Key Features

* *Algorithm Animations:* Visual representation of sorting, searching, or other key DSA concepts.
* *Smooth Navigation:* Built using *React Router* for seamless switching between different algorithm pages.
* *Smooth Scrolling:* Leveraged React's *useRef hook* for efficient DOM manipulation and smooth scroll effects.
* *Beautiful UI:* Icons integrated using *FontAwesome* and styled with modern CSS/PostCSS.

---

## 🛠️ Tech Stack

* *Frontend Framework:* React.js
* *Language:* JavaScript / TypeScript
* *Routing:* React Router DOM
* *Bundler:* Parcel / Vite
* *Styling:* CSS & PostCSS
